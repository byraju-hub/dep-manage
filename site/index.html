dep-manage

교회 부서 관리 프로그램 — 명단, 출석, 심방, 계획, 공지를 한곳에서.

이런 프로그램이에요

영 · 유아부, 유치부, 유초등부, 중고등부, 청년부 등 교회 부서를 운영하는 교역자(목사, 전도사)와 교사를 위한 웹 프로그램입니다. cafe24와 같은 PHP + MariaDB 웹호스팅에 설치해서 사용하고, 무료로 배포합니다.

주요 기능

  • 학생·교사 명단, 사진, 엑셀로 한꺼번에 넣고 내려받기
  • 출석 체크(출석·온라인·결석)와 출석률
  • 심방 기록, 연간 계획, 공지, 회의록
  • 부서마다 따로 정하는 역할(교회 관리자·부서 관리자·교사·열람)
  • 알레르기·사진 이용 동의 같은 추가 항목, 음력 생일 변환
  • 휴대폰에서도 편하게, 명단의 전화번호를 눌러 바로 전화·문자

이 페이지는 소개용이에요

프로그램은 PHP 서버가 있어야 동작합니다. 이 소개 페이지에서는 로그인하거나 데이터를 입력할 수 없고, 실제 사용은 직접 설치한 웹호스팅에서 하게 됩니다.
