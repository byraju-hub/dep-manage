# 디자인 기준

화면 설계는 디자인 캔버스에서 만들었고, 구현은 `web/` 에 있습니다. 색과 간격의 실제 값은 `web/src/app.css` 의 토큰이 기준이에요.
(캔버스 원본 파일은 저장소에서 뺐습니다. 필요하면 git 이력의 `design/` 폴더에서 되살릴 수 있어요.)

## 색

- 포인트: `#2563EB`
- 톤(배경/글자): blue `#E3ECFF/#1D4ED8`, green `#DDF5E8/#0F7B4A`, violet `#ECE5FF/#6D28D9`, sky `#DAF1FC/#0369A1`,
  pink `#FFE3EE/#BE185D`, orange `#FFEBD0/#A04A07`, teal `#D9F5F1/#0F766E`, amber `#FEF3C7/#92400E`, slate `#E8ECF3/#475467`
- 학년 색: 중1 파랑, 중2 초록, 중3 주황, 고1 분홍, 고2 보라, 고3 청록
- 캘린더 일정 5종: 사역 일정(파랑) · 생일(분홍) · 심방(초록) · 마감·후속(주황) · 회의(보라)
- 출석 상태: 출석(초록) · 온라인(보라) · 결석(빨강)

## 원칙

- 색만으로 뜻을 구분하지 않는다 (이름, 모양, 범례를 함께 쓴다).
- 모든 톤은 배경/글자 한 쌍이 4.5:1 이상 대비를 갖는다.
- 모바일은 아래 탭 메뉴, 출석·명단·심방 작성은 모바일에서 먼저 쓰기 편하게 만든다.
- 글꼴은 타이틀 · 메뉴 · 내용 세 곳을 따로 고를 수 있고, 글꼴 파일은 앱에 포함한다 (외부 글꼴 서비스를 쓰지 않는다).
