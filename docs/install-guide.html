무료 · 오픈소스 (AGPL-3.0)

dep-manage 설치 가이드

교회 부서 관리 프로그램을 내 호스팅에 설치하는 방법 — 컴퓨터를 잘 몰라도 따라 할 수 있게 순서대로 적었어요.

예상 시간: 30분 안팎 · 필요한 것: 호스팅 계정, 컴퓨터(윈도우/맥), 이 프로그램의 zip 파일

0. 시작하기 전에

호스팅웹 호스팅 한 곳이 필요해요. 카페24 같은 국내 일반 웹호스팅이면 충분하고, 가장 저렴한 상품으로도 돌아가요. 아래 세 가지가 되는지만 확인하세요.
필수 조건① PHP 8.1 이상   ② MariaDB 또는 MySQL 데이터베이스 1개   ③ Apache (보통 기본 제공)
주소도메인 맨 위(https://example.com/)에 설치해도 되고, 폴더(https://example.com/church/)에 설치해도 돼요. 설치 프로그램이 알아서 맞춰요.
보안꼭 https(자물쇠 표시) 주소로 쓰세요. 학생 정보가 들어가는 프로그램이에요.
개인정보 안내 — 학생의 이름·연락처·사진은 개인정보예요. 사용하는 교역자와 교사에게 필요한 만큼만 권한을 주고, 미성년자의 사진·정보 이용은 보호자 동의를 받아 두세요. (프로그램의 추가 항목에 '개인정보 이용 동의' 칸을 만들어 둘 수 있어요.)

1. 데이터베이스 만들기

프로그램의 모든 자료가 들어갈 '창고'예요. 호스팅 관리 화면에서 만들고, 아래 네 가지 정보를 메모해 두세요.

  • 접속 주소 (카페24는 보통 localhost)
  • 데이터베이스 이름
  • 데이터베이스 아이디
  • 데이터베이스 비밀번호

카페24의 경우

  1. 카페24 로그인 → 마이페이지(나의 서비스 관리) → 사용 중인 호스팅의 관리로 들어가요.
  2. 메뉴에서 DB 관리 또는 MySQL(DB) 정보 비슷한 이름의 항목을 찾아요. 이미 만들어진 DB의 이름·아이디가 보이고, 비밀번호는 여기서 새로 정할 수 있어요.
  3. 이 정보를 적어 둬요. (화면 이름은 카페24가 바꿀 수 있어요. 못 찾겠으면 호스팅 고객센터에 "MySQL 접속 정보를 알려주세요"라고 물어보면 돼요.)
같은 데이터베이스에 다른 프로그램(홈페이지 등)이 이미 있어도 괜찮아요. 이 프로그램의 표 이름 앞에는 dm_이 붙어서 섞이지 않아요.

2. 파일 올리기

  1. 내려받은 dep-manage-버전.zip 파일을 컴퓨터에서 압축을 풀어요. (우클릭 → 압축 풀기)
  2. FTP 프로그램(예: FileZilla)으로 호스팅에 접속해요. 접속 정보는 호스팅에서 알려준 FTP 주소·아이디·비밀번호예요.
  3. 카페24는 www 폴더가 웹사이트의 맨 위예요. 폴더에 설치하려면 www 안에 새 폴더(예: church)를 만들어요.
  4. 압축을 푼 폴더 안의 내용 전부(index.html, _app, api, install, migrations, data 등)를 방금 정한 위치에 올려요. 폴더 자체가 아니라 안에 든 것들이에요.
  5. 올리는 데 몇 분 걸려요. 끝나면 index.html과 install 폴더가 같은 위치에 보여야 해요.
호스팅의 파일 관리자(웹FTP)에서 zip을 그대로 올리고 서버에서 압축을 풀 수 있다면 그 방법이 더 빨라요.

3. data 폴더에 쓰기 권한 주기

설치 정보를 저장할 수 있도록 data 폴더를 쓸 수 있게 해야 해요. FTP 프로그램에서 data 폴더를 우클릭 → 파일 권한(속성) → 숫자 값에 707 (안 되면 777)을 넣어요. 대부분의 호스팅은 이미 되어 있어서 건너뛰어도 돼요. 설치 화면의 점검 단계에서 안 되면 알려 줘요.

4. 설치 화면 열기

  1. 브라우저에서 https://내주소/install/ (폴더에 설치했다면 https://내주소/church/install/)을 열어요.
  2. 1환경 점검 — 모두 초록색 ✓ 이면 다음으로. 빨간 항목이 있으면 그 항목 설명대로 호스팅 설정을 바꾸거나 고객센터에 문의하세요.
  3. 2데이터베이스 — 1단계에서 메모한 정보를 넣어요. 접두어는 dm_ 그대로 두면 돼요.
  4. 3교회 · 부서 — 교회 이름, 첫 부서 종류(영아부·유치부·유초등부·중고등부·청소년부·청년부·직접 설정)를 골라요. 종류에 맞는 용어와 학년 단계가 자동으로 채워져요. 샘플 데이터를 체크하면 가상의 학생·교사가 들어가서 화면을 미리 볼 수 있고, 나중에 한 번에 지울 수 있어요.
  5. 4관리자 계정 — 교회 전체를 관리할 '교회 관리자' 아이디와 비밀번호(8자 이상)를 만들어요. 잊어버리지 않게 적어 두세요.
  6. 끝나면 로그인하러 가기를 눌러 방금 만든 계정으로 들어가요.
설치가 끝나면 설치 화면은 다시 열리지 않아요(이미 설치됨 안내만 보여요). 설치 중 문제가 생기면 그 시도에서 만든 표는 자동으로 정리되니 처음부터 다시 해도 안전해요.

5. 처음 설정하기 (로그인 후)

  1. 설정 → 부서 정보에서 교회 이름과 로고(정사각형 이미지)를 넣어요. 로고는 왼쪽 위와 브라우저 탭 아이콘에 쓰여요.
  2. 설정 → 용어에서 '학생·교사·반·심방' 같은 말을 우리 교회에서 쓰는 말로 바꿔요.
  3. 설정 → 학년·반 구조에서 학년 단계와 반을 확인하고 만들어요.
  4. 교사들을 초대해요: 설정 → 사용자 → 초대 코드에서 부서와 역할을 정해 코드를 만들고, 가입 주소(…/join)와 함께 알려 주세요. 가입 신청이 오면 승인을 눌러요.
  5. 학생 명단은 학생 명단 → 엑셀 → 양식 내려받기로 양식을 받아 채워서 올리면 한꺼번에 등록돼요.
  6. 부서가 더 있다면 설정 → 부서 관리에서 추가해요(교회 관리자만). 사람마다 부서별로 역할을 정할 수 있어요.

6. 역할 한눈에 보기

역할할 수 있는 일
교회 관리자모든 부서 + 부서 추가, 교회 이름·로고, 백업, 업데이트
부서 관리자자기 부서의 명단·설정·승급·사용자 승인
부서 교사자기 부서의 출석 체크, 학생 정보 보기·고치기, 심방 기록
열람자기 부서의 명단·출석·일정 보기만 (심방 기록은 못 봐요)

한 사람이 여러 부서에 서로 다른 역할로 들어갈 수 있고, 소속이 아닌 부서는 화면에서 보이지도, 열리지도 않아요.

7. 백업과 업데이트

백업 (꼭 정기적으로)

교회 관리자로 로그인 → 설정 → 데이터 → 백업 내려받기. 전체 자료가 zip 한 개로 내려와요. 새해 승급 전, 업데이트 전에는 꼭 받아 두세요. 호스팅의 DB 백업 기능도 함께 쓰면 더 안전해요.

새 버전으로 업데이트

  1. 먼저 위의 방법으로 백업을 받아요.
  2. 새 zip의 압축을 풀고, 안의 내용을 같은 위치에 덮어써서 올려요. (data 폴더의 설정은 새 zip에 없으니 그대로 남아요.)
  3. 브라우저에서 …/install/ 을 한 번 열어요. "화면 파일을 마무리했어요"라고 나오면 성공이에요.
  4. 교회 관리자로 로그인했을 때 위쪽에 '데이터베이스 변경을 적용해야 해요'가 보이면 눌러서 업데이트 적용을 해요.

8. 문제가 생겼을 때

증상확인할 것
설치 화면이 안 열리고 빈 화면 또는 오류PHP 버전이 8.1 이상인지 호스팅 설정에서 확인하세요. install 폴더가 올라갔는지도 확인하세요.
"data 폴더에 쓰기" 가 빨간색3번처럼 data 폴더 권한을 707 또는 777로 바꾸세요.
데이터베이스에 연결하지 못했어요접속 주소·이름·아이디·비밀번호를 다시 확인하세요. 비밀번호의 특수문자나 앞뒤 공백도 확인하세요.
로그인 화면은 뜨는데 주소를 직접 입력하면 "페이지 없음"사이트 맨 위 폴더에 .htaccess 파일이 있는지 확인하세요(점으로 시작하는 파일은 FTP 프로그램에서 '숨김 파일 보기'를 켜야 보여요). 없으면 …/install/ 을 한 번 열면 만들어져요.
화면이 하얗거나 글자만 나와요업데이트 후라면 …/install/ 을 한 번 여세요. 브라우저에서 강력 새로고침(Ctrl+F5)도 해 보세요.
사진·로고가 올라가지 않아요호스팅에 GD 확장이 켜져 있는지 설치 화면의 점검 항목을 보세요. 파일이 너무 크면 줄여서 올려 보세요.
비밀번호를 잊었어요부서 관리자에게 '비밀번호 초기화'를 부탁하세요. 교회 관리자 본인은 호스팅의 DB 관리 화면에서 조치해야 하니 개발자 모임이나 이슈 게시판에 문의하세요.
